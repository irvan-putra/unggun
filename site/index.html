Unggun release checker

Unggun installs and updates Android apps straight from their release pages. A browser can't install apps, so this page does the checking part: it looks up the latest release of each GitHub project you list and gives you the APK download link. You install on your phone as usual.

Your list stays in this browser. Lookups go from your browser straight to GitHub's public API (no account, no token; GitHub allows about 60 lookups an hour per network). Nothing is installed or notified from here. A browser can't see what is installed on your phone, so type the version you have if you want an "update available" flag. Not validated on a physical phone.

Source (GPL-3.0) · Unggun is a fork of Obtainium. Check each APK's SHA-256 (shown when GitHub provides it) and the signing certificate in the release notes before installing.
